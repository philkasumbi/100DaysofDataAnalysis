Patient Risk Monitoring Dashboard
📌 Project Overview

This project analyzes patient vital signs and consciousness levels to classify clinical risk levels (Normal, Low, Medium, High) using Power BI. The dashboard provides quick insights for health monitoring and decision-making.

📊 Dataset Columns

Patient_ID – Unique patient identifier

Respiratory_Rate – Breaths per minute

Oxygen_Saturation – Oxygen level in blood (%)

O2_Scale – Oxygen therapy scale used

Systolic_BP – Blood pressure (mmHg)

Heart_Rate – Beats per minute

Temperature – Body temperature (°C)

Consciousness – A/V/P/C/U scale

On_Oxygen – 0 = No, 1 = Yes

Risk_Level – Target (Normal, Low, Medium, High)

⚡ Key Features

Distribution of patients by risk level

Relationship between vitals and risk categories

Highlighting patients with abnormal values

Interactive filters (oxygen use, consciousness, etc.)

🛠️ Tools Used

Python (Pandas) → Data cleaning & preprocessing

Power BI Desktop → Data modeling & visualization

Power Query → Additional transformations
